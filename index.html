              🔐 Para BORRAR TODOS LOS DATOS introduce la CONTRASEÑA MAESTRA:

              Exporta una copia de seguridad periódicamente para no perder información. El servidor guarda automáticamente un backup cada vez que se inicia/reinicia o restauras datos. Si algo sale mal, usa el botón naranja 🔙 para recuperarlo en 1 click.

              🚨 Por qué mis datos volvían aunque borraba la base de datos?

              Si tu app está en Render.com con BBDD Turso: la BBDD REAL está EN LA NUBE (3 réplicas en Europa). Borrar el archivo .db local o reiniciar Render NO borra NADA (es una protección para NO perder datos reales de nóminas/obras). Usa el botón ⚠️ BORRAR TODO (Incluido Nube Turso) de arriba para borrar de VERDAD y desaparecerán las obras "fantasma".
